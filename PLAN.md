# WebCrest Studios - Implementation Plan

## Project Goal
Create a high-converting portfolio website for **WebCrest Studios**.
The site must drive calls and inquiries by demonstrating expertise through a premium, high-performance interface.

## Domain
`webcrest.studios`

## Core Value Proposition
"We fix ineffective websites and build high-performance revenue generators."

## Tech Stack
- **Framework**: React (Vite)
- **Language**: JavaScript/JSX
- **Styling**: Vanilla CSS (Custom Design System for unique, premium look)
- **Deployment**: Vercel/Netlify (Recommended for Vite apps)

## Site Structure (MVP)

### 1. Hero Section
- **Headline**: Punchy, outcome-focused (e.g., "Turn Your Website Into Your Best Salesperson").
- **Subheadline**: "We design new sites and fix broken ones to get you more calls."
- **CTA**: "Get a Free Site Audit" / "Book a Strategy Call".

### 2. "The Problem" Section
- Educate the client: "Why most websites fail" (Slow, ugly, confusing).
- Agitate: "A bad site costs you customers every day."

### 3. Services
- **New Builds**: Custom, high-speed websites.
- **Fix & Optimize**: Speed improvements, design refreshes, mobile responsiveness.
- **SEO & Growth**: Getting found on Google.

### 4. Process
- Audit -> Plan -> Build -> Launch.

### 5. Contact / Footer
- Simple contact form.
- Direct phone number toggle (Sticky header?).
- Social proof (if available).

## Design System Ideas
- **Palette**: Dark Mode base (`#0f172a` or pure black) with glowing accents (Cyan/Blue/Green) for a "Tech/Optimization" feel.
- **Typography**: Modern Sans-Serif (Inter, Plus Jakarta Sans).
- **Effects**: Smooth scrolling, glassmorphism on cards, subtle entrance animations.
